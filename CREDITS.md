## Current bundled assets

The local environment could not complete HTTPS downloads from OpenGameArt during implementation, so this build uses procedural natural-scene fallback rendering and WebAudio-generated sound effects. The project keeps the source registry in `src/assets.js`, and downloaded files can be placed in `assets/images/` or `assets/audio/` later without changing the gameplay code. The current fallback art intentionally avoids hard square characters and uses rounded bodies, parallax mountains, trees, grass, rocks, and organic terrain.
